# Design System

The visual system is calm, civic, healthcare-oriented, and mobile-first. It avoids generic SaaS gradients and decorative spectacle.

CSS semantic tokens:

- `--background`
- `--foreground`
- `--surface`
- `--surface-muted`
- `--primary`
- `--primary-foreground`
- `--secondary`
- `--border`
- `--muted`
- `--muted-foreground`
- `--success`
- `--warning`
- `--danger`
- `--info`
- `--verified`
- `--stale`
- `--focus-ring`

Typography uses system font fallback with Devanagari-safe stacks. Touch targets are at least 44px.
